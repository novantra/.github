Thanks for the interest in contributing.

This repository is the public community space for Novantra. It does **not** contain product source code, so we cannot accept code pull requests here. The Novantra cloud platform and on-premise distribution are closed source.

To help, please:

- File a [bug report](https://github.com/novantra/community/issues/new?template=bug_report.yml) if something is broken.
- File a [feature request](https://github.com/novantra/community/issues/new?template=feature_request.yml) for new capabilities.
- File [docs feedback](https://github.com/novantra/community/issues/new?template=docs_feedback.yml) for documentation improvements.
- Start a [Discussion](https://github.com/novantra/community/discussions) for questions or open-ended conversation.

We close pull requests opened here with a pointer to this template. No offence intended; it just keeps contributions flowing through the right channels.
